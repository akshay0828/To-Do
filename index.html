Where should the Excel file live?

The board keeps three sheets in sync — your tasks, a summary, and a dated log of every change.

No server and no database. Nothing is stored by this page.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token → under Repository access pick Only select repositories and choose the one repo
  3. Under Permissions → Repository permissions, set Contents to Read and write
  4. Generate, copy the token, and paste it below

Never paste the token into index.html — GitHub revokes tokens it finds in a repo,
and a hosted page shows it to everyone. If the repo is public, so is the .xlsx.
